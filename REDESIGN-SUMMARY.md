# Cedar Park Business Redesigns

## Overview

Created **7 modern, sophisticated homepage redesigns** for Cedar Park businesses following the **Neighborhood Monumentalism** design philosophy.

---

## Design Philosophy: Neighborhood Monumentalism

This aesthetic movement transforms local businesses through:

- **Monumental typography** - Bold, architectural-scale headings
- **Generous whitespace** - Breathing room and spatial confidence
- **Natural color palettes** - Terra cotta, sage, charcoal, warm neutrals
- **Asymmetric layouts** - Dynamic tension and visual interest
- **Minimal text** - Essential information only, integrated as design elements
- **Expert craftsmanship** - Every detail refined with precision

### Key Principles

1. **Form operates through monumental restraint** - Large confident type balanced against vast negative space
2. **Color functions as signal and atmosphere** - Natural materials palette with strategic accent colors
3. **Typography becomes spatial sculpture** - Extreme hierarchy, oversized serifs/sans-serifs
4. **Asymmetric confidence** - Elements cluster and separate by visual weight
5. **Information lives in visual architecture** - Meaning through spatial relationships, not paragraphs

- Fixed header with minimal navigation
- Hero section with monumental typography (140-175px headlines)

- Anchored footer

## How to View

### Option 1: Index Page
Open `redesigns/index.html` in your browser to see all 7 redesigns with descriptions and navigation.

```bash
open redesigns/index.html
```

### Option 2: Individual Pages
Navigate to each redesign directly:

```bash

```

### Option 3: Local Server
For best experience, serve with a local server:

```bash
cd redesigns
python3 -m http.server 8000
# Then open http://localhost:8000
```
