## 🚀 Quick Start

```bash
# Navigate to redesigns
cd redesigns

# Install dependencies
npm install

# Run development server
npm run dev

# Visit any page:
# http://localhost:3000/blue-corn-harvest-bar-grill

# Build for production
npm run build

# Deploy to Vercel
vercel --prod
```
