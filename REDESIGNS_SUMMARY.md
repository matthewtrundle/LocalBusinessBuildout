## 🚀 Quick Start

### 1. Install Dependencies:
```bash
cd redesigns
npm install
```

### 2. Run Development Server:
```bash
npm run dev
```
Then open http://localhost:3000 and navigate to any business page:
- http://localhost:3000/blue-corn-harvest-bar-grill
- http://localhost:3000/red-horn-coffee-house
- http://localhost:3000/jester-king-brewery
- etc.

### 3. Build for Production:
```bash
npm run build
```
Creates static export in `out/` directory

### 4. Deploy:
```bash
npm install -g vercel
vercel --prod
```
Each business gets its own URL!
